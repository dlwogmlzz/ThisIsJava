# Getter & Setter

 - 외부에서 객체의 데이터를 읽을 때 메서드를 사용하는 것이 좋다.
 - 메서드로 필드값을 가공한 후 외부로 전달하는 메서드가 바로 Getter이다.
 - 클래스를 선언할 때 가능한 필드를 private로 선언해서 외부로부터 보호하고, 필드에 대한 Setter와 Getter메서드를 작성해서 필드값을 안전하게 변경/사용하는 것이 좋다.
 - 만약 외부에서 필드값을 읽을 수만 있고 변경하지 못하도록 하려면(읽기 전용) Getter메서드만 선언해도 좋고, 아니면 Setter메서드를 private접근 제한을 갖도록 선언해도 좋음.
